I build responsive, interactive and maintainable web experiences.

My work sits at the intersection of design and engineering. I take an interface from a rough idea or a Figma file and turn it into a working product — component by component, with attention to how it behaves on every screen size.

Day to day that means React development, responsive layouts, interactive UI, API integration and JavaScript applications. I write code that the next person can read, and I ship interfaces that people can actually use.

Right now I'm expanding toward backend development and the MERN stack — so I can take a project from the first pixel all the way to the database.
